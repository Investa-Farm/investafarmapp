Review Overview
A comprehensive application review was conducted using the available Investa Farm demo accounts to assess the functionality, navigation, user experience and presentation of the platform's core modules.
The review covered the Farmer and Investor accounts in detail, including their main operational, financial, investment and account-management features. The Agribusiness account was also accessed; however, further navigation was restricted by a verification requirement requesting organisation documents.
The review focused not only on whether features were present, but also on whether the information presented to users was clear, whether workflows were intuitive and whether there were opportunities to improve the overall user experience.

Wallet PIN – UX Observation
During testing of the Wallet PIN functionality, the PIN digits were completely masked during entry and confirmation.
While masking is appropriate from a security perspective, there is currently no visible option for the user to temporarily reveal the entered digits.
Recommendation
Consider introducing a Show/Hide PIN option, with the PIN remaining masked by default.
This would allow users to verify the digits they have entered before confirming their PIN and could reduce accidental PIN-entry errors while maintaining the existing security behaviour.
Classification: UX Enhancement
 Priority: Medium
Agribusiness Account Review
Access Observation
The Agribusiness demo account could be accessed initially, but further navigation was restricted by a Verification Required prompt.
The prompt requires the organisation to upload:
Registration Certificate.
Chairman's National ID (front and back).
Financial Statement.
The prompt indicates that these documents are required before accessing the partner dashboard and receiving payments.
Review Impact
Because the account was blocked at this stage, the Agribusiness modules could not be comprehensively reviewed in the same way as the Farmer and Investor accounts.
Recommendation
Since this is a demo account used for application testing, a verified demo Agribusiness account or dedicated demo mode would be useful. This would allow reviewers to access the full partner dashboard without submitting real organisational documentation.
Classification: Demo Account / Review Access
 Priority: High
This should first be confirmed with the development team as to whether the verification gate is intentional for demo accounts.
Cross-Platform UX Observations
Beyond individual account functionality, several opportunities were identified that could improve the overall experience.
Clearer Financial Status
The Farmer account presents several related financial states, including funding progress, approved applications, loans and input vouchers.
The information is useful, but the relationship between these different financial workflows could be made clearer to prevent users from confusing:
Funding → Approval → Voucher → Farm Operations → Repayment/Revenue Sharing
A clearer visual progression could help users understand where they are in the funding lifecycle.
KYC Communication
The Investor account displays KYC as an outstanding onboarding requirement.
The KYC status could be made more actionable by clearly showing:
Current verification status.
Required documents.
What completing KYC unlocks.
The next action available to the user.
This would provide greater clarity than simply displaying a document approval count.

Overall Assessment
The Farmer and Investor demo accounts provided access to a broad range of operational, financial, investment and account-management functionality. The platform presents the major workflows required for each user type in a relatively comprehensive manner.
No major functional failure was identified within the Farmer and Investor sections reviewed during this session. The main observations were centred around usability, information clarity and demo-account accessibility, rather than core functionality.
The most significant item requiring follow-up is the Agribusiness verification gate, as it prevented a complete review of the partner dashboard. The Wallet PIN entry experience also presents a reasonable UX improvement opportunity.
Overall, the application demonstrates a broad and increasingly mature feature set, with further opportunities to improve clarity, navigation and onboarding as the platform continues to evolve.

Recommended Follow-Up Actions
Check the Agribusiness demo account verification status and determine whether a verified demo account should be provided for application reviews.
Consider a Show/Hide PIN option during Wallet PIN creation and confirmation.
Improve the distinction between Primary and Secondary Markets for new investors.
Clarify the Farmer funding lifecycle across funding, approval, vouchers, repayment and revenue sharing.
Improve KYC status communication by making requirements and next steps more explicit.
Review the organisation of the Investor Profile to make investment, security and support functions easier to navigate.
Final Review Status: 🟢 Generally Functional — Minor UX Enhancements and Agribusiness Access Follow-up Required
