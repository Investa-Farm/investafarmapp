---
name: Farmer surface density
description: UX boundaries for keeping farmer home and wallet focused.
---

Farmer home should prioritize one stable farm image, current farm status, one compact wallet balance action, and only active next-step cards. Wallet should focus on balance, add/withdraw flows, PIN protection, and transaction history; account settings and security actions belong in profile.

**Why:** The farmer dashboard and wallet were repeating the same balance, account metadata, setup guidance, and technical details, making primary actions harder to find.

**How to apply:** Keep advanced tools, pension configuration, currency preferences, and security changes behind profile or focused wallet actions rather than adding more always-visible dashboard cards.
